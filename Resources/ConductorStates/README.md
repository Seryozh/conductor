# Conductor state artwork

Seven silent state loops and immediate static posters extracted from the user-selected conductor animation. Each MP4 is 360×264, 24 fps, 10 seconds. The existing app state selects the matching resource; there is no timed state progression. Reduced Motion uses the PNG poster.

States: ready, listening, recognizing, thinking, acting, checking, attention. The source board labels and frame lines are removed by cropping. The near-black matte is mapped to the UI panel surface (#17191D), removing the separate black box. Gestures and semantic outline colors remain recognizable.

These are presentation resources only. Build scripts copy this directory into the app bundle.
