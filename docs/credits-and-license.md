# Credits and licensing

This source tree is based on [Jev Voice by TypeSafe](https://github.com/ronadin2002/jev-cua), maintained by [ronadin2002](https://github.com/ronadin2002). The public repository currently has no license file. This edition does not add one.

GitHub's [licensing guide](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) explains that a repository without a license remains under default copyright rules. Public visibility and attribution alone do not grant permission to redistribute the source or a derivative fork.

## Options for the owner

1. Ask TypeSafe for written permission to publish this fork and agree on the license that covers the upstream code and the new layer.
2. Ask TypeSafe to add a license to the upstream repository, then confirm that it covers the code and contributions present in this copy.
3. Keep this integrated fork private, or publish only independently authored material that does not copy or depend on unlicensed upstream code.

Do not add a license file until the permission and scope are clear. A private launch draft is kept outside the public source commit.
